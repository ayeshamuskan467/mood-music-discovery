#  MOOD | Music Discovery

Welcome to **MOOD**, a modern music discovery website designed for people who love exploring music according to their mood and taste. 🎧

##  About The Project

**MOOD | Music Discovery** is a frontend web project created to practice **HTML and Tailwind CSS**.

The website provides a beautiful and simple interface where users can explore different music categories, artists, playlists, and moods.

## Features

*  Explore different music categories
*  Discover favorite artists
*  Explore playlists
*  Modern dark-themed design
*  Attractive purple accent colors
*  Smooth hover effects and transitions
*  Responsive design
*  Easy navigation between pages

## Technologies Used

* HTML5
* Tailwind CSS
* CSS
* Git & GitHub

## Design

The website is designed with a **modern dark music-app aesthetic**.

It includes clean cards, rounded corners, responsive layouts, hover effects, and a purple-themed color palette to create a stylish music experience.

## Learning Purpose

This project helped me practice and improve my skills in:

* HTML structure
* Tailwind CSS
* Responsive design
* Flexbox & Grid
* Cards and layouts
* Hover effects
* Navigation links
* GitHub and GitHub Pages
